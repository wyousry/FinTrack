# FinTrack

**Take control of your money.**

FinTrack is a personal finance management mobile application built with Flutter. It helps users track their income and expenses, manage budgets, and understand their spending habits.

## Features

- User authentication.
- Income and expense tracking.
- Transaction categorization.
- Monthly budget management.
- Spending insights and statistics.
- Light and dark mode.

## Tech Stack

- Flutter & Dart
- Firebase Authentication
- Cloud Firestore
- MVVM Architecture
- Repository Pattern

## Getting Started

1. Clone the repository:

   `git clone https://github.com/wyousry/FinTrack.git`

2. Navigate to the project directory:

   `cd FinTrack`

3. Install dependencies:

   `flutter pub get`

4. Configure Firebase.

5. Run the application:

   `flutter run`
